채용정보 수집기 (Job Aggregator)

신입 구직 활동을 위해 여러 채용 사이트의 공고를 한 곳에 모아 정리하는 개인용 자동화 도구입니다.

프로젝트 소개

이 프로젝트는 신입 채용 시장에서 여러 사이트(사람인, 잡코리아, CATCH, 링커리어, 자소설닷컴 등)에 흩어져 있는 채용 공고를 매일 자동으로 수집해, 개인 Notion 데이터베이스에 정리하고 마감일이 지난 공고를 자동으로 정리해주는 개인용 취업 준비 보조 도구입니다.

수집 대상은 바이오/제약/식품/화장품 품질·QA·QC·생산관리 및 은행/금융 신입 직군이며, 하루 한 번 실행되어 결과를 개인 대시보드(Notion)와 로컬 HTML 브리핑 파일로 정리합니다.

사람인 API 이용 목적

사람인이 제공하는 채용정보 API를 통해 신입 채용 공고(제약/바이오/식품/화장품 품질, 은행/금융)를 키워드·업종 코드로 조회하여, 위에서 설명한 개인용 취업 준비 파이프라인에 반영하는 데 사용할 예정입니다.

상업적 서비스가 아닌 1인 개인 사용 목적이며, 수집한 데이터를 재판매하거나 제3자에게 제공하지 않습니다.
