사람인 채용정보 조회기 (Saramin Job Search)

사람인(Saramin) 오픈 API로 관심 직군의 신입 채용 공고를 조회해 로컬 파일로 정리하는 개인용 스크립트입니다.

프로젝트 소개

이 프로젝트는 사람인이 제공하는 채용정보 오픈 API만을 사용해, 원하는 직군의 신입 채용 공고를 조회하고 그 결과를 로컬 JSON/CSV 파일로 정리하는 개인용 스크립트입니다. 조회할 직군·지역·고용형태는 코드 내 설정값(SEARCHES 목록)에서 자유롭게 바꿀 수 있어 특정 직군에 국한되지 않습니다.

사람인 API 외의 다른 채용 사이트나 외부 서비스는 사용하지 않으며, 브라우저 자동화 없이 표준 HTTP 요청(Python requests 라이브러리)만으로 동작합니다.

사람인 API 이용 목적

사람인이 제공하는 채용정보 API를 이용해, 관심 직군의 신입 채용 공고를 키워드·업종 코드로 조회하는 데 사용합니다.

상업적 서비스가 아닌 개인 구직 활동 보조 목적이며, 조회한 데이터를 재판매하거나 제3자에게 제공하지 않습니다.
